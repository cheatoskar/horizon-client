Horizon Scripts 0.1.0 (test build)

Copy into a TEST COPY of the game (not your main install):

  plugins\scripts\   ->  <game>\horizon\plugins\scripts\
  scripts\clock\     ->  <game>\horizon\scripts\clock\
  scripts\map-info\  ->  <game>\horizon\scripts\map-info\

Needs Horizon Host 0.2.0 or newer (plugin panels). Games: TM Nations ESWC, TM Sunrise, TMNF, TMUF.
Open the Horizon menu, "Horizon Scripts", tab "Scripts". Edit a .as file and save: it reloads by itself.
Guide and API: docs/scripting.md in the horizon-host repo.
